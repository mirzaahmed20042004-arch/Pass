Studio

Unlimited recording, neon waveform, male / female / original voices with strength, pitch and mic-boost sliders, noise gate and echo toggles. Real DSP: WSOLA pitch shifting + shelf-EQ timbre filtering.

Live + HUD

Real-time morphing (~90 ms blocks) and a floating HUD bubble that stays on top of every game: blue = male, pink = female. Drag it, tap to monitor, long-press for the panel.

Game broadcast

3-second countdown then max-volume speaker output that the game mic picks up - with force-speaker routing so it works even while headphones are plugged in.

Secured backend

Token-protected writes (X-VoiceFilter-Token), per-IP rate limits, strict validation, security headers, HTTPS-ready. GET/POST /api/presets, /api/health, /download.

Honest note about in-game voice changing. Android gives the microphone to exactly one app at a time - the game in front - and has no virtual-microphone API, so without root no app can inject audio into a game; Voice Filter never injects anything. It broadcasts your filtered clip out loud and the game mic hears it (force-speaker makes this work with headphones too). The HUD overlay keeps controls on top of your game, and live monitoring runs whenever Voice Filter is the foreground app.

Install

Download the APK, allow "install unknown apps", tap the file, done. Android 7.0+ (API 24). For the HUD, grant "display over other apps" when prompted. ~140 KB, no ads, no account.
