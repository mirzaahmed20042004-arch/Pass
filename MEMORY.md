# Memory and data handling

- Notes, conversation history, selected agent, model configuration, voice preference and optional gateway token are stored in Android WebView `localStorage` under `ultron-ai-state-v1`. In the browser preview, the same data is stored in that browser's local storage instead.
- This storage is app-private but **not application-level encrypted**. The optional token is stored there in plaintext. Android backup is disabled. Uninstalling or clearing app data permanently removes these records.
- Memory is a manual notes list, not a vector database, long-term model memory, contact store, or automatic extraction from other apps. Up to 200 notes can be searched and deleted; adding a new note at the limit requires deleting one first. Chat history retains the latest 100 messages. Settings can clear all local state.
- The app sends only user/model conversation messages marked for model context (up to the latest eight, truncated to 4,000 characters each) with the selected profile's instruction. Notes, local-action responses, and accessibility screen snapshots are not automatically sent to the model. A user can still explicitly type or paste private information into a prompt. Clearing history prevents a late response from being restored locally, but cannot recall a request already sent to a server.
- Accessibility snapshots may contain private non-password text from the visible app. They are captured only after a HUD long-press, displayed and stored in local chat, and are not encrypted. The accessibility service discards events and performs no continuous capture.
- When a model is configured, the server receives the prompt and may store or process it according to its own configuration. HTTP is unencrypted. The optional gateway does not itself log or persist chat bodies. Speech and browser providers have separate data practices.
